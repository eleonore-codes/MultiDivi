# MultiDivi 3.0.3

Behoben: Im Fokustraining erzeugte Einzelübungen zu Quotient oder Rest blendeten R aus. Level 2 verwendet nun auch für gezielte Wiederholungen vollständige Divisionen mit Ergebnis R Rest. Doppelte Fehler derselben Aufgabe erzeugen nur einen Fokus-Eintrag. Andere Level bleiben unverändert.

Gespeicherte alte Fokuslisten werden beim Laden auf die vollständigen Aufgaben abgebildet. Eine noch offene alte Einzelübung wird als vollständige Aufgabe neu begonnen; ihre vorherige Eingabe bleibt im Sitzungsarchiv previousComponentWork erhalten. Abgeschlossene Ergebnisse und Lernstände werden nicht gelöscht.

39 Tests bestanden, darunter vollständige Antwort 24 : 10 = 2 R 4, beide Fehlerarten, alte Fokuslisten, unveränderte fortgeschrittene Teilübungen sowie alle bisherigen Regressionen. Startseite: Version 3.0.3. Noch nicht auf GitHub veröffentlicht.
